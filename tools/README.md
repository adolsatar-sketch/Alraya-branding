# الأدوات

    pip install uharfbuzz shapely fonttools brotli skia-python cairosvg
    python3 tools/explore.py && python3 tools/export.py && python3 tools/build3.py

- `vec.py`: مسارات Skia (منحنيات حقيقية وعمليات منطقية).
- `pen.py`: قلم متغيّر السماكة مع ملاءمة منحنيات Bézier.
- `identity.py`: الاتجاهات الستة وتكويناتها.
- `mock3.py`: التطبيقات.
- `build3.py`, `site3.css`, `site3.js`: الموقع.
- `v2/`: أدوات النسخة الثانية (تبني `v2/index.html`).
