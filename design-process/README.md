## قاعدة الاختيار
- يُستبعد أي شكل يشبه أيقونة إنترنت أو شعار مقاولات تقليدياً أو حرفاً لاتينياً آخر.
- لا يُكتب لشكل ضعيف قصة لتبريره.
- اختير لكل منطق (فراغ، حروف، التقاء، تحوّل، توقيع، ختم) أقوى شكل فقط.
